1.5.0 — 13/10/2026
- Plus rien n'est supprimé : ✕, « Vider la corde » et le nettoyage automatique retirent seulement les cartes de la corde ; le fichier de la capture ou de la note reste dans le dossier. Les dernières cartes retirées reviennent d'un clic depuis le menu de la barre (Raccrocher les dernières retirées).
- Sur la carte de droite, « Vider la corde » remplace « Tout supprimer » (les cartes non épinglées sont retirées ; les cartes épinglées ou avec raccourci restent), et un nouveau bouton « Vider le presse-papiers ».
- La carte de mise à jour et de confirmation tient sur tous les écrans : les notes défilent dans leur propre zone et les boutons Oui/Non ne sont jamais coupés, quelle que soit la résolution ou la mise à l'échelle. Les notes de version s'affichent dans la langue de l'appli.

1.4.0 — 12/10/2026
- Épingler des cartes : cliquez sur la punaise en bas à droite ou clic droit → Épingler. Les cartes épinglées restent au début de la corde avec une pince bleue ; glissez-les sur le côté pour les réordonner, tirez-en une vers le bas pour la déposer dans une autre appli. « Tout supprimer » et la suppression automatique ne touchent pas aux cartes épinglées.
- Mandal démarre avec Windows (activé par défaut ; désactivable dans le menu de la zone de notification ou dans les paramètres). Si l'exe est déplacé, l'entrée de démarrage le suit.
- Un raccourci peut être une seule touche : + du pavé numérique (p. ex. pour capturer une zone), F1–F24 ou Impr. écran.

1.3.1 — 09/10/2026
- La modification des raccourcis dans les Paramètres fonctionne à nouveau : les raccourcis globaux sont suspendus tant qu'un champ de raccourci a le focus, la combinaison saisie arrive bien dans le champ (aussi pour l'attribution à une carte).
- Les valeurs de raccourci invalides du fichier de paramètres sont ignorées ; la pince d'angle est recréée si sa fenêtre se ferme de façon inattendue.
- La pince d'angle s'active/désactive désormais d'un clic depuis le menu de la barre ; clic droit sur la pince → Masquer fonctionne aussi.

1.3.0 — 09/10/2026
- Mises à jour automatiques via GitHub Releases (activées par défaut, désactivables). Les téléchargements sont vérifiés en SHA-256 ; on te demande toujours avant d'installer.
- Glisser-déposer : la pince se détache, une petite copie de la carte suit le curseur, la corde remonte pendant le glissement et revient si tu annules.
- Paramètres : encadré À propos (version, GitHub, LinkedIn, mises à jour, notes de version), mise en page compacte sur deux colonnes, bouton Appliquer.
- Notes : carte Ajouter une note, modification sur place avec le crayon, les brouillons annulés sont conservés ; sélectionne du texte sur une carte de note et relâche pour copier seulement cette partie.
- Conservation : rien n'est jamais supprimé automatiquement ; nettoyage optionnel après N jours (les cartes avec raccourci restent).
- La pince de coin peut aller dans n'importe quel coin ; la corde se range quand la souris la quitte ; Tout supprimer avec une carte de confirmation ; icône plate transparente.

1.2.0 — 09/10/2026
