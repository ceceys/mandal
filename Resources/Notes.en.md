1.3.0 — 2026-10-09
- Automatic updates from GitHub Releases (on by default, can be turned off). Downloads are verified with SHA-256 and you are always asked before installing.
- Drag and drop: the clothespin snaps off, a small copy of the card follows the cursor, the line pulls up while dragging and comes back if you cancel.
- Settings: About box (version, GitHub, LinkedIn, updates, release notes), compact two-column layout, Apply button.
- Notes: Add note card, in-place editing with the pencil, cancelled drafts are kept; select text on a note card and release to copy just that part.
- Storage: nothing is ever deleted automatically; optional auto-cleanup after N days (cards with a shortcut are kept).
- Corner clothespin can live in any corner; the line puts itself away when the mouse leaves; Delete all with an in-theme confirmation card; flat transparent icon.

1.2.0 — 2026-10-09
- Preview window: double-click to open large, resize from the edges, zoom with the wheel, optionally keep above other apps; size and position are remembered.

1.1.0 — 2026-10-09
- 12 languages, transparent line, fixed control card on the right, settings window with editable shortcuts.
- Stretching line: cards shrink at 12/16/24/32/40/50/60, the rest scrolls with arrows.
- Per-item persistent shortcuts, OCR image-to-text, day folders, hot corner, installer.

1.0.0 — 2026-10-09
- First version: region / full-screen / window capture, clipboard watching, click-to-copy, drag and drop, delete, persistent PNG, tray menu.
