1.5.0 — 2026-10-13
- Nothing is ever deleted: ✕, "Clear line" and auto-cleanup only take cards off the line; the screenshot or note file stays in the folder. Put the last removed cards back with one click from the tray menu (Put back last removed).
- On the right-hand card, "Clear line" replaces "Delete all" (unpinned cards come off; pinned cards and cards with a shortcut stay), plus a new "Clear clipboard" button.
- The update and confirmation card fits every screen: notes scroll in their own area and the Yes/No buttons are never cut off at any resolution or scaling. Release notes are shown in the app's language.

1.4.0 — 2026-10-12
- Pin cards: click the pushpin at the bottom right or right-click → Pin. Pinned cards stay at the start of the line with a blue clothespin; drag them sideways to reorder, pull one down to drag it into another app. "Delete all" and auto-delete leave pinned cards alone.
- Mandal starts with Windows (on by default; turn it off in the tray menu or Settings). If the exe is moved, the startup entry follows it.
- A shortcut can be a single key: numpad + (e.g. to capture a region), F1–F24 or PrintScreen.

1.3.1 — 2026-10-09
- Changing shortcuts in Settings works again: global hotkeys are suspended while a shortcut box has focus, so the pressed combination reaches the box (also when assigning a shortcut to a card).
- Invalid shortcut values in the settings file are ignored; the corner clothespin is recreated if its window is closed unexpectedly.
- The corner clothespin can now be toggled from the tray menu with one click; right-click the clothespin → Hide also works.

1.3.0 — 2026-10-09
- Automatic updates from GitHub Releases (on by default, can be turned off). Downloads are verified with SHA-256 and you are always asked before installing.
- Drag and drop: the clothespin snaps off, a small copy of the card follows the cursor, the line pulls up while dragging and comes back if you cancel.
- Settings: About box (version, GitHub, LinkedIn, updates, release notes), compact two-column layout, Apply button.
- Notes: Add note card, in-place editing with the pencil, cancelled drafts are kept; select text on a note card and release to copy just that part.
- Storage: nothing is ever deleted automatically; optional auto-cleanup after N days (cards with a shortcut are kept).
- Corner clothespin can live in any corner; the line puts itself away when the mouse leaves; Delete all with an in-theme confirmation card; flat transparent icon.

1.2.0 — 2026-10-09
- Preview window: double-click to open large, resize from the edges, zoom with the wheel, optionally keep above other apps; size and position are remembered.

1.1.0 — 2026-10-09
- 12 languages, transparent line, fixed control card on the right, settings window with editable shortcuts.
- Stretching line: cards shrink at 12/16/24/32/40/50/60, the rest scrolls with arrows.
- Per-item persistent shortcuts, OCR image-to-text, day folders, hot corner, installer.

1.0.0 — 2026-10-09
- First version: region / full-screen / window capture, clipboard watching, click-to-copy, drag and drop, delete, persistent PNG, tray menu.
