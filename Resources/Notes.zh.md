1.3.1 — 2026-10-09
- 设置中更改快捷键已修复：快捷键输入框获得焦点时暂停全局热键，按下的组合键会写入输入框（为卡片分配快捷键时同样适用）。
- 设置文件中的无效快捷键值会被忽略；角落夹子窗口意外关闭时会自动重建。
- 角落夹子现在可以在托盘菜单中一键开关；右键点击夹子 → 隐藏 也可以。

1.3.0 — 2026-10-09
- 通过 GitHub Releases 自动更新（默认开启，可关闭）。下载文件用 SHA-256 校验，安装前总会询问。
- 拖放：夹子弹开，卡片的小副本跟随光标，拖动时晾衣绳收起，取消后回落。
- 设置：关于框（版本、GitHub、LinkedIn、更新、更新说明），紧凑的双栏布局，“应用”按钮。
- 便签：添加便签卡片，用铅笔就地编辑，取消的草稿会保留；在便签卡片上选中文字并松开，只复制所选部分。
- 存储：从不自动删除任何内容；可选在 N 天后自动清理（带快捷键的卡片会保留）。
- 角落夹子可放在任意角落；鼠标离开时晾衣绳自动收起；“全部删除”带主题风格的确认卡片；扁平透明图标。

1.2.0 — 2026-10-09
- 预览窗口：双击放大打开，从边缘调整大小，滚轮缩放，可选保持在其他应用之上；记住大小和位置。

- 每张卡片的持久快捷键、OCR 图片转文字、按日文件夹、热角、安装程序。
