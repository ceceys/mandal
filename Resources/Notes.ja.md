1.3.1 — 2026-10-09
- 設定でのショートカット変更を修正：ショートカット欄にフォーカスがある間はグローバルホットキーを一時停止し、押したキーの組み合わせが欄に入力されます（カードへのショートカット割り当ても同様）。
- 設定ファイル内の無効なショートカット値は無視されます。隅の洗濯ばさみのウィンドウが予期せず閉じた場合は再作成されます。
- 隅の洗濯ばさみをトレイメニューからワンクリックでオン／オフできるようになりました。洗濯ばさみを右クリック → 隠す でも可能です。

1.3.0 — 2026-10-09
- GitHub Releases からの自動更新（既定でオン、オフにできます）。ダウンロードは SHA-256 で検証され、インストール前に必ず確認します。
- ドラッグ＆ドロップ：洗濯ばさみが外れ、カードの小さなコピーがカーソルに付いてきて、ドラッグ中はロープが上がり、キャンセルすると戻ります。
- 設定：情報ボックス（バージョン、GitHub、LinkedIn、更新、リリースノート）、コンパクトな 2 列レイアウト、「適用」ボタン。
- メモ：メモ追加カード、鉛筆でその場で編集、キャンセルした下書きは保持；メモカード上でテキストを選択して離すと、その部分だけコピーされます。
- 保存：自動で削除されることはありません。任意で N 日後の自動整理（ショートカット付きカードは残ります）。
- 隅の洗濯ばさみはどの隅にも置けます。マウスが離れるとロープがしまわれます。「すべて削除」はテーマに沿った確認カード付き。平らで透明なアイコン。

1.2.0 — 2026-10-09
- プレビューウィンドウ：ダブルクリックで大きく開き、端からサイズ変更、ホイールでズーム、他のアプリの上に表示（任意）。サイズと位置を記憶します。

1.1.0 — 2026-10-09
- 12 言語、透明なロープ、右側の固定コントロールカード、ショートカットを編集できる設定ウィンドウ。

- カードごとの永続ショートカット、OCR による画像→テキスト、日付フォルダー、ホットコーナー、インストーラー。
