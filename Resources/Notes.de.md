1.3.0 — 09.10.2026
- Automatische Updates über GitHub Releases (standardmäßig an, abschaltbar). Downloads werden per SHA-256 geprüft; vor der Installation wird immer gefragt.
- Ziehen und Ablegen: die Klammer springt ab, eine kleine Kopie der Karte folgt dem Mauszeiger, die Leine zieht sich beim Ziehen hoch und kommt bei Abbruch zurück.
- Einstellungen: Info-Box (Version, GitHub, LinkedIn, Updates, Versionshinweise), kompaktes zweispaltiges Layout, Übernehmen-Schaltfläche.
- Notizen: Notizkarte, Bearbeiten direkt auf der Karte (Stift), abgebrochene Entwürfe bleiben erhalten; Text auf einer Notizkarte markieren und loslassen kopiert nur die Auswahl.
- Aufbewahrung: nichts wird automatisch gelöscht; optionale Bereinigung nach N Tagen (Karten mit Tastenkürzel bleiben).
- Die Eck-Klammer kann in jede Ecke; die Leine räumt sich weg, wenn die Maus sie verlässt; „Alle löschen“ mit Bestätigungskarte im Stil der App; flaches transparentes Symbol.
