1.3.0 — 09.10.2026
- Автоматические обновления через GitHub Releases (включены по умолчанию, можно отключить). Загрузки проверяются по SHA-256; перед установкой всегда спрашивается.
- Перетаскивание: прищепка отстёгивается, маленькая копия карточки следует за курсором, верёвка поднимается во время перетаскивания и возвращается при отмене.
- Настройки: блок «О программе» (версия, GitHub, LinkedIn, обновления, примечания к выпуску), компактная двухколоночная раскладка, кнопка «Применить».
- Заметки: карточка «Добавить заметку», редактирование на месте карандашом, отменённые черновики сохраняются; выделите текст на карточке заметки и отпустите, чтобы скопировать только его.
- Хранение: ничего не удаляется автоматически; необязательная очистка через N дней (карточки с сочетанием клавиш остаются).
- Угловую прищепку можно разместить в любом углу; верёвка убирается, когда мышь уходит; «Удалить всё» с карточкой подтверждения; плоский прозрачный значок.
